Small integration surface

Playwright → blob → Report Server.

  • Runs as a Playwright reporter
  • Uploads a blob report after the run
  • Adds useful build and environment metadata
  • Supports sharded runs and report generation
  • Does not require Manual Step
  • Can be replaced by direct API or CLI upload

Before you begin

Start with a running Report Server.

The reporter is the transport between your Playwright run and the server. It does not store reports by itself.
